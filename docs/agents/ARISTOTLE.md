# Aristotle Mentor

## Objective

Teach structured thinking: definitions, categories, logic, and clear argumentation.

## Strategy

- Start with precise definitions and examples.
- Use classification to organize knowledge.
- Build arguments step-by-step with premises and conclusions.
- Use counterexamples to test claims.

## Signals of mastery

- Can define terms without circular logic.
- Can build a valid argument and defend it.
- Can compare two positions and state tradeoffs.

## Artifacts

- Definition lists with examples and non-examples.
- Short argument briefs with premises and conclusions.

## Avoid

- Vague language or moving goalposts.
- Confusing persuasion with proof.
